# Jarvis AI Assistant

A powerful AI assistant with both web and terminal interfaces that can help you with various tasks.
<img width="1012" height="637" alt="image" src="https://github.com/user-attachments/assets/a741c6d5-a885-4d76-90d2-26ad6d51aaff" />


## Features

- **Voice Recognition**: Interact with Jarvis using voice commands
- **Text Input**: Type commands when voice isn't convenient
- **Web Interface**: Beautiful HTML/CSS interface for browser-based interaction
- **GUI Interface**: Tkinter-based interface for desktop interaction
- **Terminal Mode**: Classic terminal interface for lightweight usage
- **Web Searches**: Search Google, YouTube, Wikipedia
- **Application Management**: Open applications like MS Word, Notepad, etc.
- **System Functions**: Take screenshots, open system settings
- **Conversational AI**: Basic conversation capabilities

## Requirements

- Python 3.6+
- OpenAI API Key
- Required packages (install using `pip install -r requirements.txt`):
  - openai
  - pyttsx3
  - SpeechRecognition
  - pyautogui
  - wikipedia
  - google
  - rapidfuzz
  - requests
  - flask (for web interface)
  - python-dotenv

## Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ankit2006Raj/CHATBOT-AI-ASSISTANT.git
   cd CHATBOT-AI-ASSISTANT
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure API Key**
   - Copy `.env.example` to `.env`
   - Add your OpenAI API key to the `.env` file:
     ```
     OPENAI_API_KEY=your_actual_api_key_here
     ```

4. **Run the application** (see sections below)

## Running the Web Interface (Recommended)

1. Start the Flask web server:
2. Your default browser will automatically open to `http://127.0.0.1:5000/`
3. Interact with Jarvis through the beautiful web interface

The web interface offers:

- Voice input through your browser
- Text-to-speech responses
- Animated status indicator
- Mobile-friendly responsive design

## Running the Desktop GUI

1. Run the application:
   python main.py```
2. Choose mode 1 for GUI interface

## Running in Terminal Mode

1. Run the application:
2. Choose mode 2 for Terminal interface
3. Choose your preferred input method: voice or text
