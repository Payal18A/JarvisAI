# 🤖 CHATBOT AI ASSISTANT

A Python-based AI Chatbot and Virtual Assistant that allows users to interact with the system using text and voice commands. The assistant can answer queries, search for information, perform system-level actions, and interact with different applications.

## 📌 Project Overview

CHATBOT AI ASSISTANT is a web-based AI assistant developed using Python and Flask.

The project combines Artificial Intelligence, Natural Language Processing, Speech Recognition, Text-to-Speech, and automation to provide an interactive assistant.

The user can communicate with the assistant through commands, and the assistant processes those commands to perform different tasks.

## ✨ Features

- 💬 AI-powered chatbot
- 🎤 Voice command support
- 🔊 Text-to-Speech response
- 🌐 Information search
- 📖 Wikipedia search
- 🖥️ Application and system automation
- 🖱️ Mouse and keyboard automation
- 🔍 Fuzzy command matching
- 🌐 Flask-based web interface
- 🎨 HTML, CSS and JavaScript frontend
- 🔐 Environment variable support for API keys
